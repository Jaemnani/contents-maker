# 숏폼 배포 템플릿 (플랫폼별 실전 표준)

쇼츠/숏폼 영상 1개가 완성되면, 아래 **플랫폼별 표준 형식 그대로** 문구를 뽑는다.
이것은 실제로 발행되어 검증된 형식이다. 카피 말투는 항상 `references/voice.md`를 따른다.
플레이스홀더: `[핵심요약]`, `[모델A]`, `[모델B]`, `[주제키워드]`, `[상세본문]`은 그 회차 주제에 맞게 채운다.

---

## 공통 요소

**존댓말 공통 본문** (인스타·유튜브 설명·네이버클립·틱톡에서 공유)
```
[핵심요약 1~2문장, 존댓말]. 대표 AI [모델A], [모델B]도 예외는 아니네요~ AI 체험은 aib.vote
```
- 예: "웹 검색이 없이 AI에게 질문하게 되면, 최근 내용에 대해 자신있게 틀립니다. 대표 AI 클로드, 제미나이도 예외는 아니네요~ AI 체험은 aib.vote"
- 톤: 담백한 존댓말 + "~네요~" 마무리. 과장 없음.

**전체 태그 풀** (여기서 플랫폼별로 골라 씀)
`#AI #삼성전자 #영업이익 #챗GPT #클로드 #제미나이 #AI비교 #인공지능 #주식 #주식스타그램 #테크 #aib`
- `#aib`는 어디든 항상 포함(브랜드 태그).
- 주제가 바뀌면 종목·인물 태그(#삼성전자 #영업이익)를 그 주제 키워드로 교체.

---

## 1. 인스타그램 (릴스)
- **영상 비율: 4:5** (※ 다른 플랫폼과 다름. 인스타는 4:5로 별도 리프레임한 버전 사용)
- **본문:** 존댓말 공통 본문에서 "AI 체험은 aib.vote"는 빼고, 대신 태그를 길게. (릴스는 링크 미작동)
- **태그: 많이 (약 12개).** #~스타그램 #테크 계열 포함.
```
[핵심요약 1~2문장, 존댓말]. 대표 AI [모델A], [모델B]도 예외는 아니네요~
#AI #삼성전자 #영업이익 #챗GPT #클로드 #제미나이 #AI비교 #인공지능 #주식 #주식스타그램 #테크 #aib
```

## 2. 스레드 (Threads) — 2단 구성
- **영상 비율: 9:16**
- **1번 게시물 (영상 첨부):** 짧은 훅 한 줄(반말 ~음체) + 태그 4~5개
```
[주제 훅 한 줄, ~음체] #AI #삼성전자 #인공지능 #AI비교 #aib
```
- **2번 게시물 (1번에 이어서/댓글):** voice.md 반말 풀버전 본문 + 개인 사인
```
[상세본문: 반말 ~음/~함체, 모델별 반응 대비, ㅎㅎ, 짧은 문장]
그래서 하나만 믿으면 안되고 비교해 봐야 함 aib.vote 에서 직접 넣어보기
그럼 20000
```

## 3. X (트위터) — 2단 구성
- **영상 비율: 9:16**
- **1번 게시물 (본문, 2~3줄 끊기):** 정보 압축, 마지막에 링크
```
[주제 훅 한 줄]

[모델A] "[짧은 오답 인용]"
[모델B] "[짧은 오답 인용]"

둘 다 자신있게 틀림
근데 [실제 사실]이었음 ㅎㅎ

[한 줄 교훈]
http://aib.vote 에서 비교해보기
```
- **2번 게시물 (영상 첨부):** 짧은 훅 + 태그 (스레드 1번과 동일 형식)
```
[주제 훅 한 줄, ~음체] #AI #삼성전자 #인공지능 #AI비교 #aib
```

## 4. 유튜브 (쇼츠)
- **영상 비율: 9:16**
- **제목:** 짧은 콘셉트 + 영문 해시태그
```
AI 팩트체크 #claude #gemini #samsung
```
- **설명:** 존댓말 공통 본문(aib.vote 포함) + 한글 태그
```
[핵심요약 1~2문장, 존댓말]. 대표 AI [모델A], [모델B]도 예외는 아니네요~ AI 체험은 aib.vote #쇼츠 #AI #삼성전자 #영업이익 #챗GPT #클로드 #제미나이 #AI비교 #인공지능 #주식 #aib
```

## 5. 네이버 클립
- **영상 비율: 9:16**
- **본문:** 존댓말 공통 본문을 줄바꿈으로 나눠서 (검색 노출용, 한글 위주)
```
[핵심요약 앞부분],
[핵심요약 뒷부분].
대표 AI [모델A], [모델B]도 예외는 아니네요~
AI 체험은 aib.vote
```
- **태그: 적게 (약 5개), 한글 키워드 위주**
```
#AI #클로드 #제미나이 #삼성전자 #영업이익
```

## 6. 틱톡
- **영상 비율: 9:16**
- **AI 생성 라벨 필수 ON** (사실적 AI 생성/수정 콘텐츠는 틱톡 정책상 공개 의무. 게시 후 해제 불가하니 업로드 시 켠다)
- **본문:** 콘셉트+영문태그를 앞에 두고 존댓말 공통 본문 이어붙임
```
AI 팩트체크 #claude #gemini #samsung 웹 검색이 없이 AI에게 질문하게 되면, [핵심요약]. 대표 AI [모델A], [모델B]도 예외는 아니네요~ AI 체험은 aib.vote
```
