# 말투 프로필 (Voice Profile)

이 스킬로 뽑는 **모든 카피(커뮤니티 글·스레드·X 등)는 이 말투로 작성한다.**
사용자 본인이 쓴 실제 글에서 추출한 스타일이다. AI가 쓴 티가 나면 실패다.

## 공통 원칙 (모든 채널)

- **오타는 확실히 고친다.** 브랜드명·고유명사 정확하게 (클로드, 제미나이, ChatGPT 등). ※ 예전 분석 샘플엔 오타가 있었지만, 실제 발행 카피에서는 교정한다.
- **이모지 절대 금지.** 🎉😊 같은 것 하나도 쓰지 않는다.
- **긴 대시(—) 금지.** 문장 연결은 쉼표·줄바꿈·마침표로.
- 물결(~)은 자연스럽게 사용 OK. 감탄은 "!!", 여운은 "..." 사용.
- 웃음은 **"ㅎㅎ"** 를 기본으로 (ㅋㅋ 대신 ㅎㅎ).
- **문장은 짧게, 툭툭 끊는다.** 만연체·긴 설명 금지. 한 호흡에 한 문장.
- **겸손·솔직 톤.** 과장 광고 티 내지 않는다. "솔직히", "아쉬웠어요", "부담없이" 같은 진솔한 표현 선호.
- 필요하면 **자기 얘기를 자연스럽게 깔고 시작**해도 좋다 (일상·경험을 서두에).
- **마지막에 개인 사인**을 붙여도 좋다. 블로그에서 쓰던 "그럼 20000" 같은 마무리.
- **금지 표현: "~셈".** ("~보세요", "~해봐", "~보기" 등으로 대체)

## 채널별 톤

### 커뮤니티 (존댓말 게시판 — 디시 정보성 갤·네이버 카페 등)
- "~해요", "~어요"체 + 물결. 친근한 존대.
- 예: "만들어봤어요~", "제일 좋아해요", "부담없이 쓰셔도 되고"
- 구조: 인사 → 뭐 하는 건지 → 왜 하는지 → 링크/피드백 요청. 광고 티 최소.

### 반말 익명 게시판 (디시 유동·반말 허용 게시판)
- "~음", "~임", "~함", "~옴"체. 날것의 반말.
- 예: "만들었거든", "많관부", "헤헤", "당하고 옴"
- 넋두리·경험담 톤 OK. 진솔하게.

### 스레드 (Threads)
- **일상·인사이트 공유하는 크리에이터 톤.**
- "~음", "~임"체나 친근한 평어체.
- 반말 익명 게시판 말투를 기반으로 하되, 조금 더 정돈된 크리에이터 느낌.
- 문단을 짧게 나눠 읽기 쉽게. 마지막에 개인 사인 붙여도 좋음.

### X (트위터)
- **정보 전달도 길게 쓰지 않는다. 2~3줄 단위로 끊어 가독성 확보.**
- 핵심만. 대화/인용은 짧게 따옴표로.
- 스레드보다 더 압축적.

## 좋은 예시 (삼성 89조 콘텐츠 기준)

**스레드:**
```
검색 끈 AI 둘한테 삼성 2분기 89조 영업이익 진짜냐고 물어봤음

클로드는 89조는 아닐거라고, 역대 최대가 17조인데요 이러고
제미나이는 그 숫자 오류라고, 실제론 10조4400억이라고 함

둘 다 엄청 자신있게 틀렸다고 하는데
삼성 공식발표가 진짜 89.4조였음 ㅎㅎ

검색 끄면 AI가 최신 사실 앞에서 이렇게 헛발질함
그것도 서로 다르게 틀림

그래서 하나만 믿으면 안되고 비교해봐야됨
aib.vote 에서 직접 넣어보기

그럼 20000
```

**X:**
```
검색 끈 AI한테 삼성 89조 실적 진짜냐고 물어봄

클로드 "17조가 최대인데요"
제미나이 "오류임, 실제 10조4400억"

둘 다 자신있게 틀림
근데 진짜 89.4조였음 ㅎㅎ

최신 사실은 한 모델만 믿으면 위험함
aib.vote 에서 비교해보기
```

## 체크리스트 (카피 발행 전 자가 점검)
- [ ] 이모지 없음
- [ ] 긴 대시(—) 없음
- [ ] "~셈" 없음
- [ ] 웃음은 ㅎㅎ
- [ ] 오타·고유명사 정확
- [ ] 문장 짧고 툭툭 끊김
- [ ] 광고 티/AI 티 안 남
- [ ] (선택) 개인 사인으로 마무리
